# 轮播入口图标化与锁屏标记禁用设计

## Context
当前应用存在三个需要一起处理的问题：
1. 文件夹页底部的“开始轮播~”是长条按钮，占空间较大，用户希望改为固定在底部中央的较大圆形图标按钮。
2. 锁屏标记实际体验不稳定，用户希望干脆禁用锁屏标记能力，只保留解锁后可用的标记入口。
3. 点击开始轮播后切回桌面时，壁纸有时还需要等待一段时间才正常显示；另外“避开状态栏区域”功能也希望直接移除。

## Goals
- 将文件夹页底部的轮播入口改为固定底部的大圆形按钮。
- 支持在设置页为该按钮配置自定义图片；未配置时使用默认图标。
- 禁用锁屏状态下的标记能力。
- 删除“避开状态栏区域”设置与绘制逻辑。
- 修复点击开始轮播后切回桌面时壁纸显示延迟的问题。

## Non-goals
- 不新增复杂的图标裁剪编辑器。
- 不支持网络图片或多套图标方案。
- 不重构为新的 UI 架构或拆分多个新文件。
- 不修改标记数据库结构。

## Recommended approach
采用方案 A：直接在现有文件中完成调整，不额外拆新组件文件。

这样可以最小化改动范围，避免当前代码再次因为大范围重构而出现结构性错误。改动集中在现有 UI、服务和 Manifest 中，便于快速验证。

## Design

### 1. 文件夹页底部轮播入口
- 将 `MainActivity.kt` 中 `FolderListScreen()` 底部的全宽按钮替换为固定在底部中央的大圆形按钮。
- 按钮保持当前功能：点击后进入系统动态壁纸设置页并选中 `MyWallpaperService`。
- 按钮视觉规则：
  - 默认显示应用默认图标。
  - 如果用户在设置页选择了自定义图片，则使用该图片作为按钮内容，并裁剪为圆形。
  - 为避免遮挡列表内容，底部 `Spacer` 高度需要根据圆形按钮高度重新调整。

### 2. 设置页图标配置
- 在 `SettingsScreen()` 中新增“启动轮播图标”设置卡片。
- 该卡片包含：
  - 当前图标预览。
  - “选择图片”按钮，用系统图片选择器选取本地图片。
  - “恢复默认”按钮，清空自定义图标配置。
- 通过 `SharedPreferences` 保存 `launcher_icon_uri` 字段。
- 导出/导入设置时继续保持当前 JSON 方案，但扩展支持 `launcher_icon_uri` 字段，保证换机后图标设置也能恢复。

### 3. 禁用锁屏标记
- 在 `AndroidManifest.xml` 中移除 `QuickMarkActivity` 的 `android:showWhenLocked="true"`。
- 在 `QuickMarkActivity.kt` 中移除 `setShowWhenLocked`、`setTurnScreenOn` 和旧版锁屏 flags 代码。
- 保留 `QuickMarkActivity` 作为普通快捷标记入口，但它只在设备解锁后按系统默认行为运行。

### 4. 移除状态栏避让功能
- 从 `SettingsScreen()` 中删除“避开状态栏区域”开关。
- 从 `MyWallpaperService.kt` 的 `renderBitmap()` 中删除 `exclude_status_bar` 相关判断、`drawArea` 偏移和状态栏高度估算。
- 恢复为直接对整个画布进行铺满绘制。

### 5. 壁纸显示延迟修复
- 当前问题的关键在于：进入桌面时壁纸并不总是立即完成加载与绘制，尤其是点击开始轮播后第一次回桌面时。
- 处理方式：
  1. 在 `MyWallpaperService.MyEngine` 初始化后，如果当前还没有已显示壁纸，则立即触发一次 `loadNextWallpaper()`，而不是只等待定时器。
  2. 在 `onVisibilityChanged(visible = true)` 中，如果是首次显示或当前没有已经渲染成功的位图，优先立即加载/显示，而不是仅按剩余时间继续倒计时。
  3. 保留现有“离开桌面暂停计时、回到桌面续计时”的大逻辑，但首次展示应绕过等待。
- 目标效果：点击开始轮播后切回桌面，壁纸应立刻可见，不再出现明显等待。

## Files to change
- `app/src/main/java/com/example/wallpaper/ui/MainActivity.kt`
  - 文件夹页底部按钮改为圆形图标按钮。
  - 设置页增加图标配置。
  - 删除“避开状态栏区域”设置项。
- `app/src/main/java/com/example/wallpaper/ui/QuickMarkActivity.kt`
  - 删除锁屏显示相关代码。
- `app/src/main/java/com/example/wallpaper/service/MyWallpaperService.kt`
  - 删除状态栏避让绘制逻辑。
  - 修复首次回桌面显示延迟。
- `app/src/main/AndroidManifest.xml`
  - 去掉 `QuickMarkActivity` 的锁屏显示属性。

## Validation
1. 文件夹页底部不再显示长条按钮，而是固定在底部中央的大圆形按钮。
2. 未配置自定义图片时显示默认图标；配置后显示用户选图的圆形裁剪预览。
3. 设置页可以选择和重置启动图标。
4. 锁屏状态下不再直接执行标记入口。
5. 设置页中不再出现“避开状态栏区域”。
6. 壁纸绘制恢复全屏铺满，不再做顶部避让。
7. 点击开始轮播后切回桌面，壁纸应立即显示，不再额外等待一段时间。

## Risks and mitigations
- 自定义图片 URI 可能在部分场景失效：使用系统选图返回的 URI，并在读取失败时自动回退默认图标。
- 圆形按钮过大可能遮挡列表：通过调整底部留白保证最后一个文件夹项不会被挡住。
- 首次立即加载如果与定时器叠加，可能造成重复切换：首次立即加载后应同步更新时间基准，避免紧接着又触发一次定时任务。
